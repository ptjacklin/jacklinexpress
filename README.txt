PT JACKLIN CARGO EXPRESS — WEBSITE COMPANY PROFILE
================================================
Isi:
- index.html
- style.css
- script.js
- assets/logo.png
- assets/hero-banner.png

CARA PAKAI
1. Extract ZIP.
2. Buka index.html di browser.
3. Upload seluruh folder ke hosting/public_html.
4. Ganti nomor WhatsApp admin di script.js pada variabel `admin`.
5. Ganti email, nomor telepon, alamat, dan klaim perusahaan dengan data resmi perusahaan.

Catatan:
Konten profil sengaja dibuat sebagai draft brand/company profile dan tidak mengklaim angka, cabang, armada, sertifikasi, atau pengalaman tertentu yang belum diberikan.
